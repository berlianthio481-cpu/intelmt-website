# 智医科技官网 - 图片资源说明

## 需要准备的图片资源

### 1. Logo 图片
**路径:** `images/logo.png`
**尺寸:** 建议 200x50px (2x 分辨率：400x100px)
**格式:** PNG (透明背景)
**说明:** 采用"双平行四边形交叠 + 医疗十字切割"的图形 Logo

### 2. 产品 UI 展示图
**路径:** `images/product-ui.png`
**尺寸:** 建议 800x600px
**格式:** PNG
**说明:** 展示智医产品界面的透视图，建议包含：
- 诊室听译机器人界面
- AI 全病程管理后台
- 智慧支付界面
- 互联网医院界面
可以做成拼贴图或选择一个代表性界面

### 3. 微信公众号二维码
**路径:** `images/wechat-qr.png`
**尺寸:** 建议 400x400px
**格式:** PNG
**说明:** 公司官方微信公众号二维码

### 4. 客户案例背景图 (可选)
**路径:** `images/cases-bg.jpg`
**尺寸:** 建议 1920x1080px
**格式:** JPG
**说明:** 用于客户案例模块的背景图，可以是医院实景照片

### 5. 合作医院 Logo (可选)
**路径:** `images/logos/`
**尺寸:** 建议 200x80px 统一尺寸
**格式:** PNG (透明背景或白色背景)
**说明:** 合作医院的 Logo，用于信任背书区域

---

## 临时方案

在当前阶段，图片可以暂时使用：
- **Logo:** 文字替代或临时占位图
- **产品 UI:** 用产品截图或设计稿
- **二维码:** 可以先留空或用占位图

网站代码已经做了图片加载失败的降级处理，不影响整体展示效果。

---

## 图片优化建议

1. **压缩优化:** 使用 TinyPNG 等工具压缩图片
2. **响应式:** 考虑提供 @2x、@3x 高分辨率版本
3. **WebP 格式:** 现代浏览器支持 WebP，体积更小
4. **懒加载:** 大图可以考虑懒加载提升性能
