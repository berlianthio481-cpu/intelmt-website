# 智医科技官网升级项目

## 项目概述

智医科技官方网站升级 - 第一阶段 (MVP 极简跑通版)

**网站定位:** 专业的 B2B 品牌数字展厅 + 高效的商业联络枢纽 + 自媒体内容聚合阵地

**核心目标:** 传递"为患者解忧，让医院更智慧"的使命，建立专业形象，引导访客咨询

## 本地预览

### 方法一：直接打开
```bash
# 在项目目录下直接打开
open index.html  # Mac
start index.html  # Windows
```

### 方法二：使用本地服务器 (推荐)
```bash
# 使用 Python
cd intelmt-website
python3 -m http.server 8000

# 访问 http://localhost:8000
```

### 方法三：使用 VS Code Live Server
1. 安装 Live Server 扩展
2. 右键 index.html → Open with Live Server
